# 《天下无主》v0.26.0 R26

这是面向试玩的开发候选版，不代表商业完成版或最终平衡结论。Windows、网页与 Android 三端来自同一份 Godot 源码，源码指纹与文件哈希记录在随附的 `release-manifest.json` 和 `CHECKSUMS.sha256` 中。

## 本轮主要内容

- 势力主路线：历史主人公开局、国库与公仓、城主身份分层、城防军令、独立编军、随行军团与国家供给。
- 征伐中枢：城防任命、无目标先编军、情报主官、逐步解锁天下城池、按地域或势力筛选可攻目标。
- 城池经济：人口、税基、农业、生产、工造、商队、城池特产与四档可调税率；治理能力影响征收效率，税率影响社会后果。
- 动态世界：明末各势力压力、历史因果世界线、城门榜文与势力情报；历史节点会读取当前世界状态，不机械覆盖玩家改变。
- 地图与海路：扩展至东亚、东南亚、台湾及主要海外节点；海路受船舶、人员、装备与敌方海军约束。
- 平民与东山再起路线保留，并持续受战乱、征召、屠城、商路阻断和势力扩张影响。
- UI 与操作：全鼠标操作、地图缩放和拖动、历史风格界面、固定返回层级、任务与情报追踪、战斗承伤与 NPC 忠诚行为。

## 下载

- Windows：下载 `TianxiaWuzhu-Windows-x64-v0.26.0.zip`，完整解压后运行 `TianxiaWuzhu.exe`；不要把 EXE 与 PCK 分开。
- Android：下载 `TianxiaWuzhu-Android-arm64-v0.26.0.apk`。这是面向 vivo X300 Pro 横屏基准的 arm64 开发签名包，安装时需要允许此来源。
- 网页版：GitHub Pages 提供无需安装的 WebGL2 版本；若浏览器或显卡关闭 WebGL2，请改用 Windows 版。
