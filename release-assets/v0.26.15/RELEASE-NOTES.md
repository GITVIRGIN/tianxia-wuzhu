# 天下无主 v0.26.15 · 地图、粮运与天下归心

本次更新网页版：[立即游玩](https://gitvirgin.github.io/tianxia-wuzhu/)。

## 更新内容

- 校正地图与城池位置，修正杭州、宁波、长崎及成都、重庆、云南等地的显示偏移。
- 异地征粮加入加工、在途运输、实际损耗与费用。源城扣粮、国库扣费、预计到货分别记账，不再把异地粮食视作即时可用。
- 修复城池守将身份显示和分配问题。
- 修复统一长局中发现的粮务、税粮领取、军团补给与征伐流程问题。
- 修复旧攻城损伤把后方城市长期判成前线的问题；损伤只放大真实边境或当前敌军造成的战线。
- 完善浏览器存档持久化、存档下载、开局界面、地图和弹窗操作。
- 兼容提示页的旧 EXE/APK 下载入口固定到对应历史版本，避免新版 Release 导致旧链接失效。

- `TianxiaWuzhu-Web-v0.26.15.zip`：完整浏览器运行包，解压后按 `PLAY-LOCAL.md` 启动；在线游玩无需下载。
