## 游玩与存档

网页版需要支持 WebGL2 的现代浏览器。请通过游戏中的“存档”页保存进度，也可下载当前存档作为独立备份。存档跟随浏览器和站点地址保存；本机 `127.0.0.1` 的进度不会自动出现在 GitHub Pages，不要清除需要保留进度的站点数据。

下载浏览器 ZIP 后完整解压，安装 Node.js 并运行 `PLAY_BROWSER.cmd`，或使用包内说明启动本机服务器。不要直接双击 `index.html`。
